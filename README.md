# Vacancy Analysis Application

## Приложение для поиска, анализа и управления вакансиями с платформы HeadHunter (hh.ru).

### Основные возможности:

🔍 Поиск вакансий с hh.ru по ключевым словам

💰 Фильтрация по зарплате с указанием диапазона

🏆 Топ-N вакансий по уровню зарплаты

🔤 Фильтрация по ключевым словам в описании

💾 Сохранение результатов в JSON формате

📊 Сортировка и сравнение вакансий по зарплате

### Дополнительные функции:

✅ Валидация данных вакансий

🔄 Удаление дубликатов

📁 Автоматическое создание папки для данных

🎯 Гибкая система фильтрации

💬 Интерактивный консольный интерфейс

🏗️ Архитектура

# Запуск тестов:
### Все тесты
pytest

### С покрытием кода
pytest --cov=src --cov-report=html

### Конкретный тестовый файл
pytest tests/test_vacancy.py -v

### Тесты с подробным выводом
pytest -v --tb=short
Структура тестов:

Unit тесты - тестирование отдельных компонентов
Интеграционные тесты - тестирование взаимодействия компонентов
Mock тесты - изоляция от внешних зависимостей
Fixtures - переиспользуемые тестовые данные

Пример теста:

python
def test_vacancy_creation():
    """Тест создания вакансии"""
    vacancy = Vacancy(
        "Python Developer",
        "https://hh.ru/vacancy/123",
        {"from": 100000, "to": 150000, "currency": "RUR"},
        "Test description"
    )
    
    assert vacancy.title == "Python Developer"
    assert vacancy.get_average_salary() == 125000
